Zaslon — предварительная сборка для Windows

Версия и архитектура указаны в имени архива; номер версии — в VERSION.

В комплекте:
  zaslon.exe          — приложение с панелью и значком в трее
  zaslon-recover.exe  — отдельная утилита аварийного снятия приостановок
  VERSION, LICENSE, SHA256SUMS.txt

Запуск

Распакуйте весь архив в постоянный каталог и запустите zaslon.exe.
Для обычного запуска скрипты не нужны.

Альтернатива — install.ps1 из того же выпуска GitHub. Он устанавливает комплект
в %LOCALAPPDATA%\Programs\Zaslon и создаёт ярлык без прав администратора.
Обновление сохраняет журнал и предыдущие файлы, без аварийной разморозки.
Удаление: install.ps1 -Uninstall после выхода из трея. При оставшихся
приостановках удаление отказывается продолжать. Настройки и бэкапы сохраняются.

«Открыть панель» повторно активирует уже открытое окно. Панель закрывается вместе
с Zaslon, в том числе при потере связи с его основным процессом. Закрытие окна
панели оставляет защиту работающей в трее. Для панели используется отдельный
временный профиль Edge; обычные окна браузера не закрываются.
Панель использует идентификатор Zaslon.Panel и иконку Zaslon, чтобы её окна
группировались на панели задач отдельно от Edge и других приложений.

Настройки находятся в %APPDATA%\Zaslon. Если задана переменная ZASLON_DIR,
используется указанный в ней профиль. Профиль разработки build/local-preview/profile
сам по себе в обычный запуск не переносится. Персональные настройки в архив не входят.

В новом профиле приложения не выбраны. В панели сначала задайте разрешённые
IP/страны, затем включите нужные приложения. Существующие настройки сохраняются.
Первый запуск с новым
обычным профилем включает запуск при входе в Windows; его можно отключить в меню.

После сбоя

Повторный запуск принимает подтверждённые приостановки из журнала без предварительной
разморозки. Возобновление требует свежего разрешённого результата. До первого
подтверждения настройка «Продолжать с предупреждением» не снимает эти приостановки.

Аварийное снятие приостановок — отдельное действие, прекращающее защиту.
Сначала завершите Zaslon, включая супервизор. В PowerShell для обычного профиля:

  .\zaslon-recover.exe -dir "$env:APPDATA\Zaslon"
  .\zaslon-recover.exe -dir "$env:APPDATA\Zaslon" -resume

Первая команда показывает журнал. Вторая возобновляет подтверждённые приостановки:
приложения смогут использовать текущую сеть. При ZASLON_DIR подставьте именно
активный при сбое каталог профиля. Повреждённый журнал и неопределённые операции
не исправляются вслепую; сохраните файлы и сообщение об ошибке.

Версии:
  .\zaslon.exe version
  .\zaslon-recover.exe -version

Ограничения

Zaslon приостанавливает процессы; блокировка каждого пакета до обнаружения сбоя
не гарантируется. Собственные прокси и маршрутизация VPN по процессам могут
отличаться от маршрута проверок Zaslon. Службы, WSL и контейнеры не входят
в подтверждённую поддержку. Сетевые настройки программа не меняет.

Проверены Windows-тесты, специальные процессы, обрыв IPv4 VPN и восстановление
защиты в Windows 11 VM. DNS/IPv6, настоящий сон и пользовательские сеансы
других ОС требуют отдельных испытаний.
