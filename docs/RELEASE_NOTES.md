**Предварительный выпуск**

Выпуск предназначен для проверки; готовность к повседневному использованию
пока не подтверждена. Самообновление отключено.

**Установка:** [Windows](https://github.com/avazar/zaslon/blob/dev/README.md#установка-на-windows)
или [Linux/macOS](https://github.com/avazar/zaslon/blob/dev/README.md#установка-на-linux-и-macos).
В README также описаны первый запуск, обновление, удаление и восстановление.

Пакеты собираются для Windows amd64/arm64, Linux amd64/arm64 и macOS universal.
В каждый входят приложение, независимая утилита восстановления, лицензия,
инструкция, версия и контрольные суммы SHA-256. Промежуточные пакеты доступны
в артефактах CI семь дней.

Для Windows прилагается `install.ps1`, закреплённый за версией выпуска.
Он проверяет контрольные суммы и устанавливает весь комплект без администратора.
Обновление сохраняет настройки, журнал и предыдущие файлы. Аварийное возобновление
установщиком не выполняется.
Для Linux/macOS прилагается `install.sh`: установка без sudo, проверка полного
архива, сохранение настроек и предыдущих файлов. Перед обновлением закройте
защищаемые приложения и выйдите из Zaslon; занятый профиль не изменяется.
Для офлайн-установки используйте локальные `--package` и `--checksums`
с архивом и манифестом из того же выпуска.

В новых профилях приложения не выбраны. Перед включением защиты задайте
разрешённые IP/страны и выберите нужные приложения. Приостановка процессов
не гарантирует блокировку каждого пакета при сбое VPN.

Linux требует ядра 5.3+ с доступными pidfd-вызовами. macOS-пакет имеет
подпись ad-hoc, без Developer ID и нотариального заверения. Конкурирующие
Unix-сигналы остановки/возобновления и гонка между проверкой PID и сигналом
на macOS остаются ограничениями. Проверки в CI не заменяют сетевые испытания
и проверку GUI в пользовательском сеансе на каждой платформе.
